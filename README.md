# Aygümüş Ahşap Bodrum

Bodrum ve çevresinde bahçe, otel ve dış mekân mobilyaları için ürün kataloğu ve iletişim sayfası.

## GitHub Pages

Bu depo GitHub Pages için yapılandırılmıştır. `main` dalına gönderilen değişiklikler otomatik olarak yayınlanır.

- Site giriş dosyası: `index.html`
- Görseller: `images/`
- Yayın iş akışı: `.github/workflows/pages.yml`

Not: Sosyal medya düğmeleri Aygümüş Ahşap Bodrum arama sayfalarına yönlendirir; resmi profil bağlantıları oldukları doğrulanmamıştır.
